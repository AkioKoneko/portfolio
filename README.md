## Repository Structure

- `index.html`
- `assets/images` — static artwork and original visual references
- `assets/videos` — optimized MP4 gameplay captures used by the portfolio

The site uses no framework or third-party animation library. Section tracking,
media controls, theme persistence, and reading-width preferences are implemented
with small vanilla JavaScript modules inside `index.html`.
